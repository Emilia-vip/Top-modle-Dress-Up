# Outfit Runway 🎮

Outfit Runway is a fashion game where players create outfits, rate other players’ styles, and compete for a spot on the leaderboard.

## Features
- Create and save outfits
- View your outfit on your profile
- Rate other players’ outfits with stars
- Top 3 outfits appear on the score page

## Tech Stack
- React + TypeScript
- Tailwind CSS
- Fastify
- MongoDB
- JWT Authentication

## How to Run
```bash
FRONTEND
npm install
npm run dev
BACKEND
bun install
bun run src/index.ts
